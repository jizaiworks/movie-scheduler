# 映画公開スケジューラー

映画の公開予定を **月表示 / 週表示 / リスト表示** のカレンダーで見るためのブラウザアプリです。
インストール不要で、`index.html` をブラウザ（Chrome / Edge など）で開くだけで動きます。

## 主な機能

- 公開予定を TMDb（The Movie Database）から自動取得（初期設定は日本の劇場公開日）
- 月・週・リストの3つの表示切り替え（← → キーで前後へ移動、T キーで今日に戻る）
- 手動で作品を追加・編集・削除（月表示のマスをダブルクリックしても追加できます）
- **映画館ごとの上映期間**（○月○日〜○月○日）を登録し、カレンダー上に帯で表示
- お気に入り登録（★）、タイトル検索、お気に入りのみ表示
- 表示中の期間を iCal（.ics）で書き出し → Google カレンダーや Outlook に取り込めます
- 手動データとお気に入りの JSON バックアップ・復元

## 初回セットアップ（TMDb APIキー）

1. [TMDb](https://www.themoviedb.org/) で無料アカウントを作成
2. [API設定ページ](https://www.themoviedb.org/settings/api) で API キーを申請（個人利用・無料）
3. アプリの「⚙ 設定」を開き、**API キー（v3）** または **読み取りアクセストークン** を貼り付けて保存

キーを設定しなくても、手動で追加した作品の管理はできます。

## 映画館の上映期間

映画館のサイトには上映スケジュールを取得するための公開APIがないので、上映期間は手入力で登録します。

- **映画館**：「🎦 映画館」で登録・編集します。初期状態で次の3館を登録しています。
  - TOHOシネマズ錦糸町
  - グランドシネマサンシャイン池袋
  - Tジョイプリンス品川
- **上映期間の登録**：「＋ 上映期間」から登録します。作品の詳細画面や日別画面からも登録できます。
  - 作品名は、カレンダーに読み込み済みの作品なら候補から選べて、TMDb の作品と自動で紐付きます。
  - 登録画面から、その映画館の公式スケジュールページを開けます。
  - 終了日が未定なら空欄にします。
- **表示**
  - 月表示・週表示では、上映期間を映画館の色の帯で表示します。月表示は1週あたり3段までで、超えた分は「上映 他n本」から確認できます。
  - リスト表示・日別画面では、映画館ごとの一覧で表示します。
  - ツールバーで映画館ごとに絞り込めます。
- iCal 書き出しとバックアップにも上映期間が含まれます。

## スマホで使う

GitHub Pages で公開した URL をスマホのブラウザで開き、ホーム画面に追加するとアプリのように使えます。
- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「ホーム画面に追加」

スマホでは、月表示のマスをタップするとその日の一覧が開きます。絞り込みは「絞り込み ▾」から開けます。一度開いたアプリ本体とポスター画像はキャッシュされるので、通信がない場所でも表示できます。

アプリを更新したときは、`sw.js` の `VERSION` を上げてから公開してください。スマホ側は、次に開いたときに裏で更新され、その次に開いたときから新しい版が表示されます。

## データの保存場所

- 設定・手動追加の作品・お気に入り・映画館・上映期間は、使っているブラウザの localStorage に保存されます（外部サーバーには送りません）
- ブラウザやPCを変えるときは「設定 → バックアップを書き出し / 読み込み」で移行してください
- TMDb から取得したデータは、月ごとに12時間、作品ごとの公開日は7日間キャッシュします。最新の情報が欲しいときは「↻ 再取得」を押してください

## 仕組みと注意点

- 公開日は、TMDb で各作品に登録されている指定地域の劇場公開日（通常公開を優先し、なければ限定公開）を使います
- TMDb の日本向けデータはボランティアによる登録のため、邦画の小規模公開などは漏れたり日付がずれたりすることがあります。必要に応じて手動追加で補ってください
- 1か月あたりの取得件数は「取得ページ数 × 20作品」まで（初期値は5ページ = 100作品、人気順）

## ファイル構成

```
index.html             画面
css/style.css          見た目（ダークモード・スマホ表示に対応）
js/app.js              処理（TMDb取得、カレンダー描画、保存、iCal書き出し）
manifest.webmanifest   ホーム画面に追加するための設定（PWA）
sw.js                  オフライン用のキャッシュ（Service Worker）
icons/                 アプリのアイコン
```
